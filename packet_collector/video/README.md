# Camera Recording

This is an independent camera recording tool. It opens a live preview window,
draws the current local time in the upper-right corner, and saves the same
timestamped frames to a video file. It can optionally read the latest row from
the network metrics CSV and overlay all metrics too.

## Install OpenCV

Windows virtual environment:

```powershell
python -m pip install opencv-python
```

Ubuntu:

```bash
sudo apt install python3-opencv
```

## Windows test

The built-in camera is commonly index `0`; the external `WebCamera` may be
index `1`:

```powershell
python video\record_camera.py --camera 1
```

The default output is saved under `video/recordings/` as an AVI file. Stop with
`q`, `Esc`, the window close button, or `Ctrl+C`.

## Ubuntu / Raspberry Pi

List camera devices:

```bash
ls /dev/video*
```

Then run, for example:

```bash
python3 video/record_camera.py --camera /dev/video0
```

You can also set a fixed duration and output path:

```bash
python3 video/record_camera.py \
  --camera /dev/video0 \
  --duration 60 \
  --output video/recordings/test_60s.avi
```

Read the latest metrics from a CSV generated by online analysis:

```bash
python3 video/record_camera.py \
  --camera /dev/video0 \
  --gps-csv captures/session_xxx/window_metrics_gps.csv \
  --output video/recordings/test_with_gps.avi
```

The overlay includes the CSV `index`, metrics timestamp, average RTT, jitter,
throughput, loss rate, and GCJ-02 coordinates. The CSV is read-only from the
recorder's perspective. If it does not exist or a field is empty, that field
shows `--` and recording continues.

## Capture and video together

From the project root, run the combined launcher as the normal desktop user:

```bash
bash scripts/capture_with_video.sh
```

It starts `capture-session` through `sudo`, waits for the new session directory,
then starts the camera recorder as the normal user. The default video output is
saved as `captures/session_xxx/camera_recording.avi`, and the recorder reads
`captures/session_xxx/window_metrics_gps.csv` as it grows.

If OpenCV was installed with Ubuntu's `apt`, the launcher automatically uses
system Python for the video process when the project virtual environment does
not expose `cv2`. Set `VIDEO_PYTHON_BIN` explicitly if needed.

Useful overrides:

```bash
CAMERA=/dev/video0 IFACE=wwan0 DURATION=3600 \
  bash scripts/capture_with_video.sh
```

Do not start this combined launcher with `sudo`; only its capture subprocess
uses elevated privileges.
