# Deployment Scope

This project may run on Raspberry Pi 5 devices connected through Wi-Fi, but
Wi-Fi access metrics are no longer part of the product scope.

The current target is four layers:

- IP layer.
- Transport layer.
- Application layer.
- Device runtime layer.

Out of scope:

- Wi-Fi access state such as SSID, BSSID, signal strength, frequency, and rate.
- Cellular metrics.
- RRC/Attach/TAU/PDU Session/APN/5QI.
- GPS, road-scene recognition, and video/image recognition.
- Complex web dashboard.
- Complex diagnosis system.
